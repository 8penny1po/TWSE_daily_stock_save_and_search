<h1>台股上市股票查詢系統</h1>
<h2>介紹</h2>
<h3>這是一個使用python開發的台股資料爬蟲系統，用於蒐集收盤後的資料</h3>
<h3>資料來源於TWSE台灣證券交易所</h3>
<h2>功能</h2>
<h3>取得上市股票收盤後的數據</h3>
<h3>將資料儲存成SQLite</h3>
<h3>可透過指定股票代碼,日期或漲跌價差查詢資料</h3>
<h2>使用</h2>
<h3>在gui.py運行即可</h3>

<h2>注意事項</h2>
<h3>資料不會自動儲存，必須依照格式(YYYYMMDD)輸入並點擊儲存按鈕</h3>
<h3>使用python3.14.6開發，使用這之前的版本運行可能導致代碼出錯</h3>
<h3>倘若此前沒安裝過requests請在終端上輸入pip install requests</h3>
